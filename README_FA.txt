همراه تریدر مارکت
=================
این بسته شامل فایل‌های منبع برنامه است و APK آماده نصب نیست.

روش استفاده:
1) فایل ZIP را استخراج کنید.
2) همه محتویات داخل پوشه را در ریشه مخزن GitHub برنامه دوم قرار دهید.
3) مسیر .github/workflows/build-market-apk.yml نیز باید حفظ شود.
4) در GitHub وارد Actions شوید و workflow با نام Build Market APK را اجرا کنید.
5) پس از پایان موفق، فایل APK را از بخش Artifacts دریافت کنید.

نکته: قیمت‌ها از سرویس عمومی biquote.io دریافت می‌شوند؛ پشتیبانی نمادها و دسترسی سرویس تضمین‌شده نیست.
این نسخه اتصال MT5 و معامله خودکار ندارد و محاسبه ریسک آن صرفاً آموزشی است.
